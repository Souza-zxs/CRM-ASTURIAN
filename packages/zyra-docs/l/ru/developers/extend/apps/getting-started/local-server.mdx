## Управление локальным сервером

Используйте `yarn zyra docker:*` для управления локальным контейнером Zyra:

| Команда                                | Что делает                                           |
| -------------------------------------- | ---------------------------------------------------- |
| `yarn zyra docker:start`             | Запустить сервер (при необходимости скачивает образ) |
| `yarn zyra docker:start 2.2.0`       | Запустить конкретную версию сервера                  |
| `yarn zyra docker:start --port 3030` | Запустить на пользовательском порту                  |
| `yarn zyra docker:stop`              | Остановить сервер (данные сохраняются)               |
| `yarn zyra docker:status`            | Показать URL, версию и учётные данные для входа      |
| `yarn zyra docker:logs`              | Потоковый вывод журналов сервера                     |
| `yarn zyra docker:reset`             | Стереть данные и начать заново                       |
| `yarn zyra docker:upgrade`           | Скачать последний образ `zyra-app-dev`             |
| `yarn zyra docker:upgrade 2.2.0`     | Обновить до конкретной версии                        |

Данные сохраняются между перезапусками в двух томах Docker (`zyra-app-dev-data` для PostgreSQL, `zyra-app-dev-storage` для файлов). Используйте `reset`, чтобы стереть всё.

## Фиксация версии сервера

Когда версия не передана, `docker:start` определяет версию из диапазона `engines.zyra` вашего приложения в `package.json` — того же диапазона, по которому сервер выполняет проверку при установке вашего приложения. Он запускает самый новый опубликованный образ `zyra-app-dev`, который удовлетворяет диапазону, и использует `latest`, если поле отсутствует или ни одна опубликованная версия не совпадает:

```json filename="package.json"
{
  "engines": {
    "zyra": ">=2.2.0"
  }
}
```

Передайте версию явно, чтобы переопределить диапазон для одного запуска: `yarn zyra docker:start 2.3.0`. Если контейнер уже существует с другой версией, `docker:start` обновляет его на месте (пересоздаёт контейнер с сохранением томов данных).

## Обновление образа сервера

`yarn zyra docker:upgrade` скачивает последний образ, сравнивает дайджесты и пересоздаёт контейнер только если действительно что-то изменилось. Тома сохраняются — заменяется только контейнер. Если был скачан новый образ и контейнер работал, при обновлении автоматически запускается новый контейнер; затем выполните `yarn zyra docker:start`, чтобы дождаться его готовности.

```bash filename="Terminal"
yarn zyra docker:upgrade            # Latest
yarn zyra docker:upgrade 2.2.0      # Specific version
```

Проверьте запущенную версию с помощью `yarn zyra docker:status` (эта команда показывает `APP_VERSION`, встроенную в контейнер).

## Запуск параллельного тестового экземпляра

Передайте `--test` любой команде `docker:*`, чтобы управлять вторым, полностью изолированным экземпляром — это полезно для запуска интеграционных тестов или экспериментов, не затрагивая ваши основные данные разработки:

| Команда                             | Что делает                                              |
| ----------------------------------- | ------------------------------------------------------- |
| `yarn zyra docker:start --test`   | Запустить тестовый экземпляр (по умолчанию — порт 2021) |
| `yarn zyra docker:stop --test`    | Остановить его                                          |
| `yarn zyra docker:status --test`  | Показать его статус                                     |
| `yarn zyra docker:logs --test`    | Транслировать его журналы                               |
| `yarn zyra docker:reset --test`   | Стереть его данные                                      |
| `yarn zyra docker:upgrade --test` | Обновить его образ                                      |

Тестовый экземпляр запускается в собственном контейнере Docker (`zyra-app-dev-test`) с выделенными томами (`zyra-app-dev-test-data`, `zyra-app-dev-test-storage`) и собственной конфигурацией, поэтому он может работать параллельно с вашим основным экземпляром без конфликтов. Совместите `--test` с `--port`, чтобы переопределить значение по умолчанию (2021).

## Ручная настройка (без генератора каркаса)

Пропустите генератор каркаса, если вы добавляете SDK в существующий проект:

```bash filename="Terminal"
yarn add zyra-sdk zyra-client-sdk
```

Добавьте скрипт в `package.json`:

```json filename="package.json"
{
  "scripts": {
    "zyra": "zyra"
  }
}
```

Теперь вы можете запускать `yarn zyra dev`, `yarn zyra docker:start` и остальные команды.

<Note>
Не устанавливайте `zyra-sdk` глобально — фиксируйте версию в каждом проекте, чтобы каждое приложение использовало свою собственную версию.
</Note>
