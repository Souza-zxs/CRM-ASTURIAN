Помимо `dev`, `dev:build`, `dev:add` и `dev:typecheck`, CLI `yarn zyra` предоставляет команды для выполнения функций, просмотра логов и управления установками приложений.

## Выполнение функций (`yarn zyra dev:function:exec`)

Запустите логическую функцию вручную, не вызывая её через HTTP, cron или событие базы данных:

```bash filename="Terminal"
# Execute by function name
yarn zyra dev:function:exec -n create-new-post-card

# Execute by universalIdentifier
yarn zyra dev:function:exec -u e56d363b-0bdc-4d8a-a393-6f0d1c75bdcf

# Pass a JSON payload
yarn zyra dev:function:exec -n create-new-post-card -p '{"name": "Hello"}'

# Execute the post-install function
yarn zyra dev:function:exec --postInstall
```

## Просмотр логов функций (`yarn zyra dev:function:logs`)

Потоковая передача журналов выполнения логических функций вашего приложения:

```bash filename="Terminal"
# Stream all function logs
yarn zyra dev:function:logs

# Filter by function name
yarn zyra dev:function:logs -n create-new-post-card

# Filter by universalIdentifier
yarn zyra dev:function:logs -u e56d363b-0bdc-4d8a-a393-6f0d1c75bdcf
```

<Note>
Это отличается от `yarn zyra docker:logs`, который показывает логи контейнера Docker. `yarn zyra dev:function:logs` показывает журналы выполнения функций вашего приложения с сервера Zyra.
</Note>

## Генерация типизированного клиента (`yarn zyra dev:generate-client`)

Повторно сгенерируйте типизированный API‑клиент (`zyra-client-sdk`) из схемы активного удалённого экземпляра, не выполняя сборку или синхронизацию приложения. Используйте это, чтобы получить типизированного клиента в любом проекте — например, в backend‑сервисе в отдельном репозитории — который взаимодействует с вашим экземпляром Zyra:

```bash filename="Terminal"
# In your project (no Zyra app definition required)
yarn add zyra-sdk zyra-client-sdk

# Connect to the Zyra instance to generate the client from
yarn zyra remote:add

# Generate the typed client into node_modules/zyra-client-sdk
yarn zyra dev:generate-client
```

Затем импортируйте клиента в свой код:

```typescript
import { CoreApiClient } from 'zyra-client-sdk/core';
```

Повторно запустите команду при каждом изменении вашей модели данных, чтобы обновить сгенерированные типы.

<Note>
Клиент генерируется внутри `node_modules`, поэтому он не добавляется в ваш репозиторий вместе с кодом. Запускайте `yarn zyra dev:generate-client` после каждой установки (например, в скрипте `postinstall` или в CI).
</Note>

## Удаление приложения (`yarn zyra app:uninstall`)

Удалите свое приложение из активного рабочего пространства:

```bash filename="Terminal"
yarn zyra app:uninstall

# Skip the confirmation prompt
yarn zyra app:uninstall --yes
```

## Управление удалёнными серверами

**Remote** — это сервер Zyra, к которому подключается ваше приложение. Во время настройки скаффолдер автоматически создаст его для вас. Вы можете в любой момент добавлять новые удалённые серверы или переключаться между ними.

```bash filename="Terminal"
# Add a new remote (opens a browser for OAuth login)
yarn zyra remote:add

# Connect to a local Zyra server (auto-detects port 2020 or 3000)
yarn zyra remote:add --local

# Add a remote non-interactively (useful for CI)
yarn zyra remote:add --url https://your-zyra-server.com --api-key $ZYRA_API_KEY --as my-remote

# List all configured remotes
yarn zyra remote:list

# Set the active remote
yarn zyra remote:use <name>
```

Ваши учётные данные хранятся в `~/.zyra/config.json`.
