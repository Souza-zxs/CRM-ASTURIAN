## الأوامر المفيدة

يجب تنفيذ هذه الأوامر من مجلد packages/zyra-server.
من أي مجلد آخر يمكنك تشغيل `npx nx {command} zyra-server` (أو `npx nx run zyra-server:{command}`).

### إعداد المرة الأولى

```
npx nx database:reset zyra-server # إعداد قاعدة البيانات مع بذور التطوير
```

### بدء الخادم

```
npx nx run zyra-server:start
```

### Lint

```
npx nx run zyra-server:lint # مرر --fix لإصلاح أخطاء التدقيق
```

### تجربة

```
npx nx run zyra-server:test:unit # تشغيل اختبارات الوحدة
npx nx run zyra-server:test:integration # تشغيل اختبارات التكامل
```

ملاحظة: يمكنك تشغيل `npx nx run zyra-server:test:integration:with-db-reset` في حالة احتياجك لإعادة تعيين قاعدة البيانات قبل تشغيل اختبارات التكامل.

### إعادة تعيين قاعدة البيانات

إذا أردت إعادة تعيين قاعدة البيانات وزرع بعض البيانات فيها، يمكنك تشغيل الأمر التالي:

```bash
npx nx run zyra-server:database:reset
```

### عمليات الترحيل

#### للكائنات داخل مخططات Core/Metadata (TypeORM)

```bash
npx nx run zyra-server:database:migrate:generate
```

## "التقنية المستخدمة"

تستخدم Zyra بشكل أساسي NestJS للواجهة الخلفية.

Prisma كان أول ORM استخدمناه. ولكن للسماح للمستخدمين بإنشاء الحقول والعناصر المخصصة، كان من المنطقي استخدام مستوى أقل حيث نحتاج إلى تحكم دقيق. الآن يستخدم المشروع TypeORM.

إليك شكل العناصر التقنية الآن.

* [NestJS](https://nestjs.com/)
* [TypeORM](https://typeorm.io/)
