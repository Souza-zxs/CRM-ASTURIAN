Kromě `dev`, `dev:build`, `dev:add` a `dev:typecheck` poskytuje `yarn zyra` CLI příkazy pro spouštění funkcí, zobrazení logů a správu instalací aplikací.

## Spouštění funkcí (`yarn zyra dev:function:exec`)

Spusťte logickou funkci ručně bez vyvolání přes HTTP, cron nebo databázovou událost:

```bash filename="Terminal"
# Execute by function name
yarn zyra dev:function:exec -n create-new-post-card

# Execute by universalIdentifier
yarn zyra dev:function:exec -u e56d363b-0bdc-4d8a-a393-6f0d1c75bdcf

# Pass a JSON payload
yarn zyra dev:function:exec -n create-new-post-card -p '{"name": "Hello"}'

# Execute the post-install function
yarn zyra dev:function:exec --postInstall
```

## Zobrazení logů funkcí (`yarn zyra dev:function:logs`)

Streamujte výstupní logy běhu logických funkcí vaší aplikace:

```bash filename="Terminal"
# Stream all function logs
yarn zyra dev:function:logs

# Filter by function name
yarn zyra dev:function:logs -n create-new-post-card

# Filter by universalIdentifier
yarn zyra dev:function:logs -u e56d363b-0bdc-4d8a-a393-6f0d1c75bdcf
```

<Note>
To se liší od `yarn zyra docker:logs`, který zobrazuje logy kontejneru Docker. `yarn zyra dev:function:logs` zobrazuje logy běhu funkcí vaší aplikace ze serveru Zyra.
</Note>

## Generování typovaného klienta (`yarn zyra dev:generate-client`)

Znovu vygenerujte typovaného klienta API (`zyra-client-sdk`) ze schématu aktivního vzdáleného serveru, bez sestavování nebo synchronizace aplikace. Použijte jej k získání typovaného klienta v libovolném projektu – například backendové služby v samostatném repozitáři – který komunikuje s vaší instancí Zyra:

```bash filename="Terminal"
# In your project (no Zyra app definition required)
yarn add zyra-sdk zyra-client-sdk

# Connect to the Zyra instance to generate the client from
yarn zyra remote:add

# Generate the typed client into node_modules/zyra-client-sdk
yarn zyra dev:generate-client
```

Poté klienta importujte ve svém kódu:

```typescript
import { CoreApiClient } from 'zyra-client-sdk/core';
```

Spusťte příkaz znovu pokaždé, když se změní váš datový model, abyste aktualizovali vygenerované typy.

<Note>
Klient je vygenerován uvnitř `node_modules`, takže není verzován spolu s vaším kódem. Spusťte `yarn zyra dev:generate-client` po každé instalaci (například ve skriptu `postinstall` nebo v CI).
</Note>

## Odinstalace aplikace (`yarn zyra app:uninstall`)

Odeberte svou aplikaci z aktivního pracovního prostoru:

```bash filename="Terminal"
yarn zyra app:uninstall

# Skip the confirmation prompt
yarn zyra app:uninstall --yes
```

## Správa vzdálených serverů

**Remote** je server Zyra, ke kterému se vaše aplikace připojuje. Během nastavení jej generátor kostry automaticky vytvoří. Můžete kdykoli přidat další vzdálené servery nebo mezi nimi přepínat.

```bash filename="Terminal"
# Add a new remote (opens a browser for OAuth login)
yarn zyra remote:add

# Connect to a local Zyra server (auto-detects port 2020 or 3000)
yarn zyra remote:add --local

# Add a remote non-interactively (useful for CI)
yarn zyra remote:add --url https://your-zyra-server.com --api-key $ZYRA_API_KEY --as my-remote

# List all configured remotes
yarn zyra remote:list

# Set the active remote
yarn zyra remote:use <name>
```

Vaše přihlašovací údaje jsou uloženy v `~/.zyra/config.json`.
