`npx nx`를 사용해 리포지토리 루트에서 명령을 실행할 수 있습니다. 명시적으로 대상 지정하려면 `npx nx run {project}:{command}`를 사용하세요.

## 앱 시작하기

```bash
npx nx start asturian-front          # Frontend dev server (http://localhost:3001)
npx nx start zyra-server         # Backend server (http://localhost:3000)
npx nx run zyra-server:worker    # Background worker
```

## 데이터베이스

```bash
npx nx database:reset zyra-server                          # Reset and seed database
npx nx run zyra-server:database:migrate:prod               # Run migrations
npx nx run zyra-server:database:migrate:generate --name <name> --type <fast|slow>  # Generate a migration
```

## 린팅

```bash
npx nx lint:diff-with-main asturian-front    # Lint changed files (fastest)
npx nx lint:diff-with-main zyra-server
npx nx lint asturian-front --configuration=fix  # Auto-fix
```

## 타입 검사

```bash
npx nx typecheck asturian-front
npx nx typecheck zyra-server
```

## 테스트

```bash
# Frontend
npx nx test asturian-front                          # Jest unit tests
npx nx storybook:build asturian-front               # Build Storybook
npx nx storybook:test asturian-front                # Storybook tests

# Backend
npx nx run zyra-server:test:unit                # Unit tests
npx nx run zyra-server:test:integration         # Integration tests
npx nx run zyra-server:test:integration:with-db-reset  # Integration with DB reset

# Single file (fastest)
npx jest path/to/test.test.ts --config=packages/{project}/jest.config.mjs
```

## GraphQL

```bash
npx nx run asturian-front:graphql:generate                        # Regenerate types
npx nx run asturian-front:graphql:generate --configuration=metadata  # Metadata schema
```

## 번역

```bash
npx nx run asturian-front:lingui:extract   # Extract strings
npx nx run asturian-front:lingui:compile   # Compile translations
```

## 빌드

```bash
npx nx build zyra-shared   # Must be built first
npx nx build asturian-front
npx nx build zyra-server
```
