## Getting Started

This app was scaffolded with a local Zyra server running at [http://localhost:2020](http://localhost:2020).

Login with the default development credentials: `tim@apple.dev` / `tim@apple.dev`.

Run `yarn zyra help` to list all available commands.

## Useful Commands

- `yarn zyra dev` - Start the development server and sync your app
- `yarn zyra docker:status` - Check the local Zyra server status
- `yarn zyra docker:start` - Start the local Zyra server
- `yarn test` - Run integration tests
